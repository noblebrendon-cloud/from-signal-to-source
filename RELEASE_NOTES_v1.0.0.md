# v1.0.0 Release Notes

## From Signal to Source — Initial Public Release

This release establishes the first public version of the From Signal to Source methodology.

### Release contents
- Eight bounded agent roles covering signal extraction through distribution.
- Master orchestrator prompt.
- Executable prompt for each stage.
- Explicit research disconfirmation and evidence-audit requirements.
- Theory-refinement step requiring the evidence to be allowed to alter the starting thesis.
- Publication-architecture and distribution boundaries.
- Machine-readable stage envelope schema.
- Human-readable PDF and editable DOCX guide.
- Worked example.
- Citation and Zenodo metadata.

### Validation status
The workflow is derived from a completed end-to-end article-development process and formalized as a reusable method. Version 1.0.0 is an initial public methodology release; it is not represented as peer reviewed or independently validated.
